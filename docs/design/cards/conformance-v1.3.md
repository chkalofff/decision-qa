# Соответствие карточек ассистента макету «Рамс» (option-c) — v1.3

Дата проверки: 22.10.2026.
Порции v1.3: 4372aaa (база), cb6339b (правила), bcc25ff (вопросы), 1d1303a
(контекст/пресет), 394663a (прогон), bd02d79 (прогресс/«Прервано»),

Плюс фиксы этой сверки (незакоммичены, см. раздел «Исправлено на месте»).

## Метод

- Приложение поднято на изолированном порту :8001 (пользовательский :8000
  не трогали); поверх — прокси :8002 с инжекцией harness-скрипта из /tmp
  (сидирование localStorage и живые вызовы `handleProposal`/`handleTrial`/
  `handleAnalysis`/`handleQueue`; в репозиторий ничего не писалось).
- Persist-кадры: сидирование `dq-assistant-chat` + `dq-workspace` →
  перезагрузка → восстановление ленты. Живые кадры: вызовы тех же
  обработчиков, что дёргает SSE-поток; развороты/раскрытия/«Принять» —
  настоящими кликами в браузере.
- Синтетический воркспейс: 8 файлов `interview_01…08.txt`, 5 вопросов,
  правила (2 исхода), результаты 8×2 модели, 14 меток исходов + метки
  вопросов — дельты и цены гейтов считались честно («ошибок 6 → 1»,
  «8 меток (5 ✓, 3 ✗)», «10 меток» у гейта исхода).
- Ширина: только 1440px (панель 460px, как фрейм макета). Узкий прогон
  550px сознательно пропущен по решению владельца — адаптивность этих
  карточек в этой сверке не проверялась.
- Прогресс-карточка 4.2/4.2а: живой SSE-поток без chat-модели недоступен;
  проверена статичной репликой разметки 1:1 по `trialProgressCard()`
  (те же классы/структура/тексты) + терминал «Прервано» поднят настоящим
  `handleTrial({aborted:true})`.
- Контроль: `node frontend/tests/run.mjs` — 268/268; `pytest -q` —
  419 passed, 1 skipped.
