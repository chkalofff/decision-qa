## Определения метрик

- **phantom rate** — доля chat-записей, где финальный ответ содержит claim
  о прогоне/карточке/повторной попытке без соответствующего события
  (`trials`/`proposals`) в записи; правила — те же regex'ы, что у находок
  аудита (`_TRIAL_CLAIM_RE`/`_PROPOSAL_CLAIM_RE`/`_GENERIC_CLAIM_RE`).
- **validation-loop** — серия из ≥2 подряд идущих шагов со `status=="error"`
  одного и того же tool внутри одной записи; «серия 3+» — петля длины ≥3.
- **guard-rescue rate** — доля записей, где среди `steps` есть шаг
  `phantom_guard`, `degrade_guard` или `retry`.
- **fallback rate** — доля записей с `fallback == true` (запасной шаг при
  исчерпании MAX_STEPS).
